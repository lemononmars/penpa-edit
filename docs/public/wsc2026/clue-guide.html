WSC 2026 clue formats

Practice room · Puzzle editor

Select the variant in the editor dropdown, then use normal marks or the WSC clue editor. Its object keys are variant IDs. Each value is an array of clues. Cells use zero-based coordinates: row 0, column 0 is the top-left cell. Clues are included in saved puzzle links.

{"trishula":[{"cells":[{"row":0,"col":0},{"row":1,"col":1}],"tips":[{"row":0,"col":2},{"row":0,"col":3},{"row":1,"col":3}]}]}

Use digit encodings 1–9 for alphabet puzzles. For S for Sudoku, derive the allowed digits from the puzzle's supplied word mapping; the booklet's Spanish mapping is an example, not a universal default. Missing Thermo supports branches through the optional paths field. Clone Along Line accepts either direction for each line pair. Different clues in Next to x and Magic Sword share one unknown digit/strength.

Nonstandard layouts

The WSC practice room has a separate Layout solver for Samurai, Expanded and Star. Supply every row, column and region explicitly; the ordinary square-grid editor cannot infer those layouts. A blank Samurai template provides geometry only; add givens, component rules and cross-grid clone lines before solving.
